Set up RustDesk

Do this ahead of time

This page covers RustDesk only. You need one Windows laptop for the session. Work through the steps below before the day of your test or assessment.

Install RustDesk from my ZIP

Required

We use the self-hosted RustDesk build from the ZIP folder I send you on WhatsApp. Complete the installation before the session and check that RustDesk opens correctly.

Show the RustDesk steps
  1. Download the ZIP folder I send you on WhatsApp. Do not install RustDesk from the internet.
  2. Unzip or extract the folder.
  3. Open the extracted folder and run the .bat file.
  4. Let the PowerShell window run — it will automatically download and launch RustDesk.
  5. Click Install when the RustDesk window appears.
  6. Click Accept and Continue. Both of these steps are necessary for a complete setup.
  7. Keep the PowerShell window open until it finishes and shows a message similar to “Press any key to close this window.”
  8. Find your machine or device ID inside RustDesk and send the code through WhatsApp.
Use only the provided self-hosted build. The regular RustDesk download from the internet will not work for this session because it is not configured for our self-hosted connection. The ZIP build is the intended and more secure option for this setup.
Important: steps 5 and 6 are required. If RustDesk still shows Install on the left side, the setup is not complete. Finish both buttons and wait until PowerShell shows a message similar to “Press any key to close this window.”
Never share a password. The machine code is not your Gmail password or any other account credential.

What I do with your code

Good to know

I use the machine code only to connect to your laptop for the session itself. I do not need your email password, your Windows password, or any other login.

Questions? Everything goes through WhatsApp.
